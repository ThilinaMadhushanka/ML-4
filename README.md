## 📄 Description

This notebook demonstrates key signal processing concepts using Python (NumPy, SciPy, and Matplotlib). It is a practical exercise aimed at familiarizing students with:

- Generating and analyzing sinusoidal signals
- Performing frequency analysis with FFT
- Filtering using FIR filters
- Upsampling and downsampling signals

<img src="https://github.com/Govindv7555/Govindv7555/blob/main/49e76e0596857673c5c80c85b84394c1.gif" width="100%" height="95px">

## 🛠️ Code Details

### 1. Signal Generation
- Sinusoidal signals (e.g., sine and cosine) are created based on frequency, amplitude, and sampling rate.
- Demonstrates aliasing and reconstruction with plots.

### 2. Fourier Transform
- Frequency analysis using `numpy.fft.fft` and `fftshift`.
- Plots magnitude spectra to identify dominant frequency components.

### 3. Filtering
- FIR filter designed with `scipy.signal.firwin`.
- Applied to the input signal using `lfilter` to reduce noise or shape the spectrum.

### 4. Sampling
- **Downsampling**: Reduces the sampling rate of the signal and discusses the aliasing effect.
- **Upsampling**: Increases the signal sampling rate and uses interpolation to fill in values.
- Visual comparison between original and resampled signals.
